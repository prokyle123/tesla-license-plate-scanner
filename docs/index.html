Why it exists

Tesla records the moment. This helps find it again.

TeslaCam archives can become a pile of video segments. The scanner samples the footage, preserves the source context, and makes detections easier to review in one place.

TeslaCam indexing

Indexes RecentClips, SentryClips, and SavedClips from a USB drive, external SSD, NAS, TeslaUSB backup, or copied archive.

◎

Local AI detection

Sends sampled frames to a compatible local CodeProject.AI custom license-plate endpoint and records confidence with source context.

Aa

Optional OCR

Can use Tesseract OCR and/or a compatible local AI OCR endpoint as a review aid for detected plate regions.

⇄

Duplicate reduction

Uses nearby timing, source clips, camera views, position, confidence, and OCR details so repeated frames do not overwhelm the results.

⌕

Searchable dashboard

Review detections by time, camera, clip, confidence, OCR text, event, and locally generated visual previews.

◉

Scanner health

Tracks queued work, scanner status, live logs, local settings, and CodeProject.AI availability from a responsive Flask interface.

Workflow

From built-in cameras to a searchable dashboard.

01Tesla recordsDashcam, Sentry, or Saved Clip footage is stored in TeslaCam folders.
02Footage is preservedTeslaUSB is optional; use a USB drive, mounted backup, NAS share, or copied archive.
03Frames are sampledThe scanner finds compatible clips and processes frames at a configurable interval.
04Review locallyAI detection and optional OCR become searchable, clip-linked dashboard records.
Architecture

Works beside TeslaUSB, but does not require it.

TeslaUSB can provide the in-car capture and backup layer on a Raspberry Pi. This project can then scan its saved TeslaCam folders, or any compatible footage folder available to your Linux host.

Installation

Deploy it on a Raspberry Pi, mini PC, Linux box, or home server.

The installer sets up the local app and systemd services. Configure the TeslaCam folder path and your local CodeProject.AI endpoint, then open the dashboard from a trusted device on your network.

Open full installation steps

What you need

  • Linux host with Python 3 and sufficient local storage.
  • TeslaCam footage on local or mounted storage.
  • CodeProject.AI Server with a compatible custom plate-detection endpoint.
  • Optional Tesseract OCR for local text extraction.
  • A trusted private-network device to access the dashboard.
Privacy and accuracy: This project is meant for reviewing footage you are entitled to access. OCR and AI output can be wrong, especially with motion blur, rain, glare, darkness, distance, or compression. It does not perform vehicle-owner lookup, and it should not be used as a substitute for human review.
