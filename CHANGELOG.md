# Changelog

All notable changes to Tesla License Plate Scanner are documented here.

## [1.0.0] - 2026-06-26

### Added

- First public repository release.
- TeslaUSB and TeslaCam workflow documentation.
- Detailed CodeProject.AI Server setup guide for Docker, ARM64, and Raspberry Pi deployments.
- Example Docker Compose files for x64 and Raspberry Pi CodeProject.AI instances.
- Accurate synthetic dashboard preview modeled on the real dashboard layout.
- GitHub release notes and source-release packaging workflow.

### Included capabilities

- TeslaCam folder ingestion for RecentClips, SentryClips, and SavedClips.
- Configurable CodeProject.AI plate detection and object detection endpoints.
- Optional Tesseract and CodeProject.AI OCR.
- Local SQLite result storage, generated media cleanup, review dashboard, and systemd services.

### Security and privacy

- No Tesla footage, detection crops, SQLite database, local configuration, or model weights are included in the repository or release archive.
